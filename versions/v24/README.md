# V24 — анатомия головы Деда Мороза

Архив rebuild_source.zip содержит точные исходники локальной версии V24: build.py, scan_rings.txt, rig_template.glb (встроенный скелет и исходная анимация). Распакуйте в одну папку, установите Python, NumPy и SciPy, выполните `python build.py`. Будет создан ded_moroz_v24_head_rig.glb и head.npz. Прямой бинарный экспорт GLB 18 065 860 байт не загружен в репозиторий; исходники позволяют его восстановить.

Результат локальной сборки: 226183 вершины, 448756 треугольников, 52 сустава, 1 клип. SHA-256 локального GLB: 0926eb3c431d99c45751c36bed2471439189e3adfdcf2786d2cb5838eb12817a. SHA-256 архива: 47b3cef948a0edae64808e542771688beeb3696acc0f424df86e4d4c1c644db1. Побайтовая идентичность на других версиях NumPy/SciPy не гарантируется.

Изменения: скулы, нос, губы, глазницы, шея, сглаживание макушки, более экономная сетка. Только нейтральная анатомическая голова, без волос, бороды, очков и текстур. Оценка 5,5/10; уши и веки требуют доработки, деформации при анимации не проверены. Поверхность реконструирована по измеренным сечениям Lee Perry-Smith (Infinite Realities, CC BY 3.0), а не импортирована напрямую. Источник: https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/LeePerrySmith . Лицевой риг отсутствует.

Ветка ded-moroz-project изолирована. Не сливать с main, не развёртывать как сайт.

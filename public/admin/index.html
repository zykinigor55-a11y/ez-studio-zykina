Вход в галерею

Введите свой пароль. Сохранённый GitHub-ключ будет расшифрован только в этом браузере.

Пароль не отправляется на сервер. Сохранённый ключ работает только в этом браузере и пока действителен в GitHub.

В первый раз подключите свой GitHub-токен. Можно защитить его собственным паролем, чтобы больше не вводить токен на этом устройстве.

Выберите уникальный пароль. Токен сохраняется здесь только зашифрованным; если очистить данные браузера, потребуется снова ввести GitHub-токен.

Без отметки выше токен хранится только в памяти открытой вкладки. Не передавайте токен и пароль другим людям.

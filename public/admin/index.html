Фотографии произведения

Добавьте крупные планы фактуры. Существующие макродетали сохраняются.
Выбери JPG, PNG или WebP прямо с компьютера. На каждой интерьерной миниатюре есть крестик × для удаления. После удаления сохраните изменения в GitHub.
MP4 или WebM, до 25 МБ. Выбери файл — он будет загружен в GitHub после «Сохранить в GitHub» и появится на сайте через автосинхронизацию MCHost.

Новые изображения преобразуются в WebP. Файлы не отправляются на сервер до нажатия «Сохранить в GitHub». Удалённые из галереи фотографии останутся в репозитории для возможного восстановления.

Вход в галерею

Введите свой пароль. Сохранённый GitHub-ключ будет расшифрован только в этом браузере.

Пароль не отправляется на сервер. Сохранённый ключ работает только в этом браузере и пока действителен в GitHub.

В первый раз подключите свой GitHub-токен. Можно защитить его собственным паролем, чтобы больше не вводить токен на этом устройстве.

Выберите уникальный пароль. Токен сохраняется здесь только зашифрованным; если очистить данные браузера, потребуется снова ввести GitHub-токен.

Без отметки выше токен хранится только в памяти открытой вкладки. Не передавайте токен и пароль другим людям.

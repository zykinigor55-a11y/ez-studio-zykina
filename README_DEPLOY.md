# Студия Екатерины Зыкиной — публикация на Render

Сборка подготовлена для отдельного GitHub-репозитория. Не размещайте её в существующем проекте Forma Visual.

1. На GitHub создайте новый пустой публичный репозиторий, например `ez-studio-zykina`.
2. Распакуйте архив и загрузите `render.yaml`, `public/index.html`, `public/robots.txt` и всю папку `public/assets/` в этот репозиторий.
3. В Render откройте My Workspace → New → Static Site и подключите новый репозиторий.
4. Настройки: Build Command = `echo ready`, Publish Directory = `public`, ветка = `main`. Или импортируйте `render.yaml` как Blueprint.
5. Render создаст публичную ссылку вида `https://ez-studio-zykina.onrender.com` (точное имя и URL назначает сервис).
6. Проверьте видео на компьютере и телефоне. Важно: форма контакта пока является демо и не отправляет заявки.
7. После подключения реальных контактов и юридической информации удалите тег noindex и robots.txt запрет индексации.

Содержимое изображений сохраняет исходные картины и включает копии улучшенного качества. Исходный ZIP не удаляйте.

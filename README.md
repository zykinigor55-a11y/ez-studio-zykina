# Дед Мороз — PUNKT / Character Studio

Отдельный проект персонажа фильма «Пункт возврата желаний». Ветка предназначена только для хранения исходников персонажа. Не сливать с main. Не развёртывать как сайт.

## Состояние на 26.11.2026
- Исходная модель V6: 274183 треугольника, 143200 вершин.
- Черновой GLB-риг: 52 сустава, 4 веса на вершину, 3-секундная тестовая анимация.
- UV, Base Color, Normal, Roughness: 4096×4096.
- V7: тесты рендера. Нужна художественная переработка анатомии, сетки, одежды, волос и материалов.
- Нет IK, лицевого рига и симуляции ткани; веса и деформации не проверены художественно.
- Требования: настоящая редактируемая полигональная модель, скелет и тесты движений; показывать реальный 3D-рендер, а не сгенерированные иллюстрации.

## Хранение
Полный локальный проект сохранён в ded-moroz-project.bundle (около 70 MiB, полный Git-архив, исходный коммит d927cfd60d41ed4ad3522138359f6ed61fd5117e). На момент создания этой ветки крупные бинарные ресурсы ещё не загружены. Скрипт риггинга и манифест размещены отдельно. Не считать ветку полной копией проекта.

Ожидаемые файлы полного проекта: model/01_ded_moroz.glb, model/ded_moroz_rig_v01.glb, model/01_ded_moroz.obj, model/BaseColor.jpg, model/Normal.png, model/Roughness.png, model/UV_layout.png, source/rig.py, source/render_v7.py, source/scene3d.json, reference/, preview/.

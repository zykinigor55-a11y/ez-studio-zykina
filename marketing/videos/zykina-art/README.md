### Монтаж и этика подачи

- Два женских голоса — заказчица и художница; русский язык.
- Динамичная инструментальная музыка, мягкие звуки клавиатуры, шелест материалов, аккуратные звуки выбора палитры.
- Появление выносок синхронизировать с ASMR, не перекрывать саму картину.
- Материалы **не приписывать конкретному произведению**, если фактический состав не подтверждён автором.
- Размеры на макете считать демонстрацией согласования, не утверждёнными размерами конкретного заказа.
- Сгенерированное интерьерное изображение маркировать как **визуализация**, а не фото реальной квартиры.
- Фотографии картин, их пропорции, художественную фактуру и цвета не изменять.
- Впечатление должно быть премиальным, без навязчивых переходов.

### Как сохранить MP4 в этот каталог

1. Скачайте `ZYKINA_ART_Premium_Film_v6_1080p.mp4` из чата.
2. Откройте эту папку на GitHub.
3. **Add file → Upload files**, перетащите MP4 и подтвердите коммит.
4. Сравните размер файла и SHA-256 с указанными выше. После проверки обновите статус в этом README.

В будущем здесь удобно хранить и отдельные короткие ролики по каждой картине: `warm-horizon-15s.mp4`, `earth-gold-15s.mp4`, `turquoise-horizon-15s.mp4`.

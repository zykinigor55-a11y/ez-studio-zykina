# Как добавить картину через GitHub

Сайт сам проверяет ветку main каждые 5 минут. После успешного обновления новая работа появится в галереях 03 и 04 и получит отдельную страницу. Раздел 02 не изменяется.

1. Откройте public/assets/картины и загрузите новую папку, например 19.
2. Положите в неё фотографии JPG, JPEG, PNG или WebP. Общий вид назовите главная.jpg (или главная.png), детали — детали 1.jpg, детали 2.jpg.
3. Создайте в этой же папке описание.txt. Пример:

```text
Название: Белая волна
Коллекция: Пластика
Материал: Гипс, акрил на холсте
Размер: 80 × 100 см
Цена: По запросу
Описание: Рельефное панно в светлых оттенках для современного интерьера.
Главная: главная.jpg
```

Коллекции: Пластика, Абстракция, Образы, Истории.

4. Сохраните загрузку в main. Подождите примерно 5 минут; большой архив может потребовать дополнительного времени.

Главное изображение можно явно выбрать строкой «Главная: имя файла.jpg». Если описание.txt отсутствует, папка 19 будет показана как «Работа 19» в «Образах». Папка с понятным названием получит это название. Размер и материал программа не угадывает — добавьте их в описание.txt.

Для временного скрытия добавьте «Публиковать: нет». Чтобы удалить работу с сайта, удалите её папку из GitHub. Последующие успешные обновления уберут её из каталога, страницы и карты сайта. Файл «работа.json» у существующих работ хранит утверждённые названия и главные виды; описание.txt имеет приоритет над ним.

Статус последней публикации: https://zykina-art.ru/assets/catalog/deployment.json (номер коммита, время и количество работ). Ошибки обновления сохраняются в папке ez-publisher на хостинге, вне публичного сайта; при ошибке посетители продолжают видеть предыдущую версию.

GitHub-репозиторий публичный. Не загружайте в него пароли, личные документы и неопубликованные материалы. Скрипт не использует секреты GitHub или пароль хостинга. Для остановки обновлений отключите задание EZ Studio GitHub sync в ISPmanager → Планировщик CRON.

SEO-страницы и sitemap.xml создаются автоматически, но добавление сайта в поисковые системы и разрешение индексации в robots.txt — отдельная настройка.

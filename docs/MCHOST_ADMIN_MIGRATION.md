# ZYKINA ART: перенос входа в админку на MCHost

Новый адрес: https://zykina-art.ru/admin/index.html

Админка является статическим HTML/CSS/JS-приложением. Публикуется из public/ существующим процессом синхронизации MCHost. Ссылка в подвале ведёт на российский домен. Резервная загрузка изображений с Render удалена; изображения запрашиваются с российского домена. API GitHub и Яндекс Метрики, авторизация, функции публикации сохранены.

## Проверка перед отключением Render

1. Открыть новый адрес после синхронизации MCHost, проверить загрузку интерфейса и отсутствие ошибок в консоли.
2. Подключить существующий GitHub-токен через форму админки. Зашифрованное локальное хранилище токена привязано к домену; данные входа с Render автоматически не переносятся. Не публиковать токен в репозитории и не передавать в переписке.
3. Проверить загрузку каталога, фотографий и видео, предпросмотр статьи и экспорт без публикации.
4. Подключить токен Метрики с правом чтения через интерфейс и проверить отчёты.
5. При необходимости проверить публикацию согласованного тестового изменения и его синхронизацию с MCHost. Только после этого отключать исключительно сервис ez-studio-zykina на Render. Остальные сервисы не затрагивать.

Старая копия Render остаётся резервной до подтверждения работы нового адреса. Сам сервис Render этим изменением не отключается.
